ExpenseLens — Personal Expense Analysis & Visualization Dashboard

ExpenseLens is a Python-based web application that helps users record, manage, and analyze their daily expenses through an interactive dashboard.

Features

- Add daily expenses
- Categorize expenses
- Calculate total expenses
- View expense records
- Visualize expenses using Pie and Bar Charts
- View Monthly Expense Trends

Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib

Installation

Install the required libraries:

pip install streamlit pandas matplotlib

Run the Project

streamlit run app.py

Project Goal

The goal of ExpenseLens is to make personal expense tracking simple through data analysis and visualization.

Future Improvements
